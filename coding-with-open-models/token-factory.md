# Coding with Nebius Token Factory

[Token Factory](https://tokenfactory.nebius.com/) hosts open models.

Explore:

- [Models available on Token Factory](https://tokenfactory.nebius.com/endpoints)
- [Intelligence vs Pricing for current models in Token Factory](https://sujee.github.io/practical-llm-evals/inference/nebius-token-factory/)

Here is how to get started.

## Prerequisites

Install one of the following coding agents:

- Claude Code
- Codex
- Cursor
- OpenCode
- Cline

## Step 1: Sign up

Go to <https://tokenfactory.nebius.com/> and sign up.

## Step 2: Get an API Key

Create an API key from the Token Factory console.

## Step 3: Add credit to your account

Apply the provided credit code to your account.

## Step 4: Follow coding agent setup

Follow the [instructions to set up agents with Token Factory](https://github.com/nebius/token-factory-cookbook/tree/main/coding).
